# Point of Interest Spec

This file defines the first points of interest for the home-region tutorial map.

The first POIs should teach the player what exploration is for.
Each POI should introduce a different kind of interaction.

The first POIs should not all be resource nodes.
They should teach curiosity, danger, and reward.

## Purpose

The first POI set should teach:
- exploring away from settlement is worth it
- not every discovery is combat
- some discoveries are risky
- greater danger can give greater reward

The first tutorial POIs should create a simple progression of confidence.

## First POI Trio

The first home-region map should use this trio:

1. `Broken Watchtower`
2. `Animal Den`
3. `Bandit Camp`

These three POIs provide:
- one discovery / curiosity site
- one natural hostile site
- one human hostile site

This gives the player variety and teaches three different exploration behaviors.

## Placement Order

The POIs should not all be equally distant from the settlement.

Recommended order from closest to farthest:

1. `Broken Watchtower`
2. `Animal Den`
3. `Bandit Camp`

This supports the tutorial flow:
- first explore
- then face danger
- then choose to challenge something more serious

## POI 1: Broken Watchtower

### Role

The Broken Watchtower is the first curiosity POI.

It should teach:
- exploration can pay off
- not every discovery requires combat
- the surrounding region has history

### Player Feeling

The player should feel:
- this looks important
- I want to inspect it
- there may be something useful here

### Interaction Type

First version:
- inspect
- loot

Later possible expansion:
- climb or restore
- reveal nearby map area
- uncover clue about another POI

### Risk Level

Low.

This should not be the first major combat teaching point.
It can have implied danger, but it should mainly reward investigation.

### Reward Direction

Possible early rewards:
- food
- scrap metal
- cloth
- simple leader item
- local clue

Good special reward examples:
- crude knife
- padded wrap
- old buckler

### Design Value

The Broken Watchtower has strong long-term value because it can later become:
- a scouting point
- a restored lookout
- a map reveal location
- a signal point

## POI 2: Animal Den

### Role

The Animal Den is the first natural hostile POI.

It should teach:
- the wild is dangerous
- local exploration has real combat risk
- combat can exist outside of human conflict

### Player Feeling

The player should feel:
- this could be dangerous
- I might want to approach carefully
- winning here should give practical rewards

### Interaction Type

First version:
- inspect
- provoke encounter
- fight or retreat

Later possible expansion:
- track signs nearby
- clear nest fully
- repeated wildlife threat behavior

### Risk Level

Medium.

This should be the first manageable hostile encounter.

### Reward Direction

Possible early rewards:
- meat
- hide
- bones or trophies later
- simple crafting materials

This POI should reward the player with practical survival value rather than rare treasure.

## POI 3: Bandit Camp

### Role

The Bandit Camp is the first serious human hostile POI.

It should teach:
- hostile people guard value
- human threats are more deliberate than wildlife
- greater danger can lead to stronger rewards

### Player Feeling

The player should feel:
- this is more dangerous than the den
- there is probably real loot here
- attacking this is a choice, not a default step

### Interaction Type

First version:
- inspect
- attack
- retreat

Later possible expansion:
- stealth approach
- bargain or bluff
- raid at different times

### Risk Level

Higher than the Animal Den.

This should be the first POI that feels like a serious challenge.

### Reward Direction

Possible early rewards:
- stolen food
- scrap metal
- valuables later
- stronger leader gear chance

Good special reward examples:
- rusted sword
- rough shield
- tougher armor scrap

This POI should be the first place where the player feels they might get stronger gear.

## Reward Philosophy

The first tutorial POIs should reward three different things:

### Broken Watchtower
- curiosity reward
- clue reward
- first exploration payoff

### Animal Den
- survival reward
- practical materials
- first combat payoff

### Bandit Camp
- danger reward
- strongest early loot
- strongest early leader upgrade chance

This creates a clear progression of reward value.

## Tutorial Role of the POIs

The three POIs together should teach:

### Broken Watchtower
- explore

### Animal Den
- survive

### Bandit Camp
- challenge

That is the intended tutorial arc.

## What to Avoid

Do not make the first POIs:
- all resource extraction spots
- all hostile
- all loot containers
- all text-only interactions

Each one must feel distinct.

## Summary

The first home-region POIs should be:
- `Broken Watchtower`
- `Animal Den`
- `Bandit Camp`

This gives the tutorial map a strong early arc:
- curiosity first
- danger second
- major challenge third
